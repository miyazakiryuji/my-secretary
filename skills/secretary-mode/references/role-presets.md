# 役割プリセット集（仕事の型の唯一の正）

秘書は「誰に仕えるか」で気くばりの中身が変わる。setup の面談（質問1「お仕事・役割は？」）の
答えから、いちばん近い型を秘書が**選んで提案**し、`/my-secretary:role` でいつでも決め直せる。
どの型でも標準フォルダと全スキルは同じ。**型が変えるのは次の5つだけ**:

1. 追加フォルダ（1〜2）
2. 朝会で必ず聞くこと（1つ）／夕会で必ず聞くこと（1つ）
3. 秘書がとくに気をつけること（2〜3）
4. 定型業務の候補（業務手順に覚えさせると楽になるもの。紹介するだけで、勝手に作らない）
5. 秘書の記憶の初期値（1〜2行。「仕事のパターン」に入る）

## 型の一覧

| # | 型 | こんな人 |
|---|---|---|
| 1 | 営業・顧客対応 | 商談・訪問・見込み客の追いかけが仕事の中心 |
| 2 | 企画・事務・バックオフィス | 社内外の依頼・締切・書類を回す |
| 3 | 管理職・チームリーダー | メンバーの相談・会議・判断が多い |
| 4 | フリーランス・個人事業主 | 複数の案件と請求・契約を自分で回す |
| 5 | 講師・教育 | 講義・研修・受講生対応 |
| 6 | 学生・研究 | 授業・課題・研究の締切 |
| 7 | 家庭・プライベート中心 | 家のこと・家族の予定・買い物 |
| 0 | 決めない | 標準の気くばりだけ（あとで決められる） |

自由記述（例: 医療事務、店舗のオーナー）も可。いちばん近い型をベースに、秘書が上の5項目を
**同じ粒度で組み立てて提案 → 承認**で使う。2つの型にまたがる人（例: エンジニア兼講師）は、
主な型を1つ選び、もう1つの型の**追加フォルダだけ**を足してよい。

## 1. 営業・顧客対応

- 追加フォルダ: `商談/`（相手先ごとの進み具合。1相手先1ファイル）
- 朝会で聞く: 今日の商談・訪問と、追いかける案件
- 夕会で聞く: 進んだ案件と、次に打つ手
- 気をつける: 返事待ちは3日で督促を提案／会う前の準備（人物メモ）を勧める／商談の翌日にお礼を勧める
- 定型業務の候補: 週次の案件報告／月初の目標確認／商談後のお礼と議事メモ
- 記憶の初期値: 案件は相手先の名前で呼ぶ

## 2. 企画・事務・バックオフィス

- 追加フォルダ: `依頼/`（受けた依頼。1依頼1ファイル。誰から・いつまで を必ず添える）
- 朝会で聞く: 今日の締切と、受けている依頼の状況
- 夕会で聞く: 片づいた依頼と、待たせている相手
- 気をつける: 締切の前日に確認を入れる／依頼は受けた日と期限をセットで記録
- 定型業務の候補: 月次の締め作業／週報／備品・経費の申請
- 記憶の初期値: 依頼は「誰から・いつまで」で記録する

## 3. 管理職・チームリーダー

- 追加フォルダ: `メンバー/`（1on1 の記録。1人1ファイル）、`会議/`（会議ごとのメモ）
- 朝会で聞く: 今日の会議と、メンバーに返す判断・相談
- 夕会で聞く: 決めたことと、待たせていること
- 気をつける: メンバーの評価・機微な事情は書かない（仕事を進める記録だけ）／自分の作業時間の確保を提案／会議の前に論点を1枚に
- 定型業務の候補: 週次の 1on1／月次の報告／評価期の準備
- 記憶の初期値: 会議の前に論点を1枚にまとめる

## 4. フリーランス・個人事業主

- 追加フォルダ: `案件/`（案件ごとの進み具合と納期）、`請求・契約/`（見積・請求・契約の記録。金額は書かなくてよい）
- 朝会で聞く: 今日の納期と、見積・請求の締切
- 夕会で聞く: 案件ごとの進み具合と、請求できるもの
- 気をつける: 納期は締切として管理／月初に請求作業を思い出させる／営業と作業の時間配分を見る
- 定型業務の候補: 月初の請求書作成／見積書の作成／確定申告に向けた月次の整理
- 記憶の初期値: 案件名で呼ぶ／請求は月初にまとめて行う

## 5. 講師・教育

- 追加フォルダ: `講義準備/`（回ごとの準備メモ）、`質問対応/`（受講生からの質問と回答）
- 朝会で聞く: 今日の講義・研修と、準備の残り
- 夕会で聞く: 講義でうまくいったこと・次回直すこと
- 気をつける: 受講生の個人情報は書かない／講義の前日に準備を確認／終わった直後にふりかえりを勧める
- 定型業務の候補: 講義前日の準備／講義後のふりかえりと資料修正／課題のレビュー
- 記憶の初期値: 講義は回番号で呼ぶ／前日に資料の最終確認をする

## 6. 学生・研究

- 追加フォルダ: `授業/`（科目ごとのメモ）、`課題/`（提出物と期限）
- 朝会で聞く: 今日の授業と、提出期限が近い課題
- 夕会で聞く: 進んだ課題と、勉強した時間
- 気をつける: 提出期限は締切として管理／試験前は勉強時間の配分を提案
- 定型業務の候補: 週の課題確認／レポートの下書きから提出まで／試験前の復習計画
- 記憶の初期値: 課題は科目名＋期限で記録する

## 7. 家庭・プライベート中心

- 追加フォルダ: `家のこと/`（用事・手続き）、`買い物/`（買うものリスト）
- 朝会で聞く: 今日の家の予定（送り迎え・通院・来客）と買うもの
- 夕会で聞く: 済んだ用事と、明日の家族の予定
- 気をつける: 家族の予定を優先して段取りする／手続きの期限は締切として管理
- 定型業務の候補: 週の献立と買い出し／月の支払い・手続き／季節の準備
- 記憶の初期値: 家族の予定は名前つきで記録する

## 0. 決めない

- 何も足さない。標準の朝会・夕会だけ。CLAUDE.md の「役割に合わせた気くばり」節は
  「役割: 決めない（`/my-secretary:role` でいつでも決められます）」の1行にする。

## 型の当てはめ方（setup / role 共通）

1. 型を決めたら、追加フォルダを `init_workspace.py --extra "案件,請求・契約"` で作る（既存はスキップ）。
2. 執務室 `CLAUDE.md` の「役割に合わせた気くばり」節を書く（無ければ足す・あれば**この節だけ**置き換える）。
   節の書式は `claude-md-template.md` の同名の節に従う。
3. 「フォルダの使い分け」表に追加フォルダの行を足す。
4. `プロフィール.md` の「仕事の型」を**提案 → 承認**で更新する。
5. 記憶の初期値を `秘書の記憶.md` の「仕事のパターン」に日付つきで追記し、1行報告する。
6. 定型業務の候補を**1回だけ**紹介する（「『請求書の手順を覚えて』と言えば登録できます」の趣旨）。
   勝手に業務手順のファイルは作らない。
