# ファイル書式テンプレート集（唯一の正）

秘書が作る・追記するファイルは、すべてこの書式に従う。
`{{ }}` は実際の値に置き換える。日付は必ず Bash の `date` コマンドで取得する（推測しない）。

- 今日の日付: `date +%F` → `2026-07-24`
- 曜日: `date +%a` の結果を 月/火/水/木/金/土/日 に読み替える（または `date +%u` で 1=月）
- 時刻: `date +%H:%M`
- ISO週番号: `date +%G-W%V` → `2026-W30`

共通ルール:

- 既存ファイルは**上書きしない**。追記か新規作成のみ。例外は秘書が管理する2ファイル:
  §8 の `申し送り.md`（最新の状態に書き直してよい）と §9 の `秘書の記憶.md`
  （追記・整理・「忘れて」による行削除ができる）。
- 記録したら「どこに保存したか」を1行添えて報告する。
- チェックボックスは `- [ ]` / `- [x]` の標準記法（集計に使うため崩さない）。

---

## 1. タスク（タスク/{{YYYY-MM-DD}}.md）— 1日1ファイル

```markdown
# {{YYYY-MM-DD}}（{{曜}}）のタスク

- [ ] ★ {{最優先タスク}}
- [ ] {{タスク}}
- [ ] {{タスク}}（持ち越し: {{MM/DD}}から）

## 途中で入ってきたこと

- [ ] {{タスク}}

## メモ

-
```

- `★` は今日の最優先（原則1つ）。
- 朝会からの繰り越しには `（持ち越し: MM/DDから）` を付ける。
- 日中の「タスク追加」は上のリストへ、割り込み仕事は「途中で入ってきたこと」へ。
- 期日のあるタスクは末尾に `（締切: YYYY-MM-DD）`。「金曜まで」等の相対表現は
  `date` で実日付にしてから書く（詳細は執務室スキル deadline-watch）。

## 2. 受信箱（受信箱/{{YYYY-MM-DD}}.md）— 1日1ファイル

```markdown
# 受信箱 {{YYYY-MM-DD}}

- {{HH:MM}} {{メモの内容そのまま}}
- {{HH:MM}} {{メモの内容そのまま}}
```

- 「メモ ◯◯」と言われたら、内容を**要約しすぎず**そのまま書き留める。
- 整理（各フォルダへの移動）は「受信箱整理」と言われたときだけ行う。

## 3. アイデア（アイデア/{{YYYYMMDD}}_{{短いタイトル}}.md）— 1アイデア1ファイル

```markdown
# {{タイトル}}

- 記録日: {{YYYY-MM-DD}}
- 状態: 種 <!-- 種 / 育成中 / 実行へ / 見送り -->

## どんなアイデア？

{{本人の言葉をベースに1〜3行}}

## きっかけ・背景

-

## 次の一歩（もしやるなら）

-
```

## 4. ノート（ノート/{{短いタイトル}}.md）— 調べたこと・ナレッジ

```markdown
# {{タイトル}}

- 記録日: {{YYYY-MM-DD}}
- タグ: {{例: 営業, AI活用}}

## 内容

{{本文}}

## 出典・リンク（あれば）

-
```

## 5. 日報（日報/{{YYYY-MM-DD}}.md）— 夕会で秘書が書く

```markdown
# 日報 {{YYYY-MM-DD}}（{{曜}}）

## 今日できたこと

- [x] {{完了タスク}}

## できなかったこと → 明日へ

- [ ] {{未完タスク}}（明日の朝会で拾います）

## 気づき・学び

- {{本人が話したこと。なければ「特になし」}}

## 秘書からひとこと

> {{秘書の口調で、今日の具体的な成果に触れた労いを1〜2行}}
```

```markdown
## 持ち越し

## 今週のハイライト

- {{本人が答えた「今週いちばん良かったこと」}}

## 気づき・学び

## 来週の重点（3つまで）

1.
2.
3.

## 秘書からひとこと

> {{1週間の傾向に触れた前向きな一言}}
```

## 7. プロフィール（プロフィール.md）— setup で作成、基本情報と目標

```markdown
<!-- あなたの基本情報。変わったときは秘書が提案してから更新します。手で直してもOK。 -->
# プロフィール

## 基本

- 呼ばれ方: {{呼び名}}
- 役割・仕事: {{役割}}

## いま頑張っていること・目標

- {{面談で聞いた内容}}
```

- 目標・役割など**基本情報の変化**はここへ。**追記・変更は提案して承認を得てから**書く。
- 好み・言い方・仕事のパターンの学びは、ここではなく `秘書の記憶.md`（§9）へ。

## 8. 申し送り（申し送り.md）— セッションをまたぐ引き継ぎ

```markdown
# 申し送り

- 更新: {{YYYY-MM-DD}} {{HH:MM}}

## いま進行中のこと

- {{◯◯: △△まで完了。次は□□から}}

## 次に開いたときにやること

- 

## 気にしていたこと（メモ）

- 
```

- 執務室直下に1ファイルだけ。**常に最新の状態だけを書く**（全体を書き直してよい唯一のファイル）。
- 10行程度まで。長い経緯は日報・ノートへ。詳細は執務室スキル handover。

## 9. 秘書の記憶（秘書の記憶.md）— 使うほど育つ、秘書の頭の中

```markdown
# 秘書の記憶

<!-- {{秘書名}}が{{呼び名}}{{敬称}}について学んだこと。秘書が追記・整理して育てます。
     手で直しても消してもOK（「それ忘れて」でも消せます）。 -->

## 呼び方・言葉

- {{YYYY-MM-DD}}: 「あの件」＝◯◯プロジェクトのこと

## 好み・スタイル

- {{YYYY-MM-DD}}: 日報のひとことは2行まで

## 仕事のパターン

- {{YYYY-MM-DD}}: 午前に集中作業がはかどる

## やらないこと（NG）

- {{YYYY-MM-DD}}: 絵文字は増やさない
```

- 1行1学び・日付つき。カテゴリに合わなければ見出しを足してよい。
- 秘書が管理するファイル: 追記に承認は不要（ただし追記したら1行報告）。
  「それ忘れて」で該当行を削除。運用の詳細は執務室スキル learning。
- **機密情報・他人の個人情報・ネガティブな人物評は書かない**。
