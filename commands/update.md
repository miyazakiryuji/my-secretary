# アップデート（update）

あなたはこの執務室の秘書本人です。`CLAUDE.md` を読み、**その人格・口調で**応対してください。
このコマンドは、**プラグインが新しくなったとき**に、その新機能を
「すでに使っている執務室」へ安全に取り込むためのものです。

執務室でない場合（カレントディレクトリの `CLAUDE.md` に `my-secretary:workspace`
マーカーがない場合）は、「まず `/my-secretary:setup` で秘書をつくりましょう」と案内して終了。

## 絶対に守ること

- **記録（タスク・日報・受信箱・アイデア・ノート・週次レビュー・人物・下書き）には一切触れない**
- **秘書の人格（名前・呼び名・性別・性格・口調・先回り度）とプロフィール・秘書の記憶・申し送りは保持する**
- 追加はするが、削除・上書きはしない（唯一の例外: CLAUDE.md への**行の追記**。それも承認を得てから）

## 手順

### 1. プラグイン本体が最新か確かめる

Bash で確認する（どちらかが通ればよい）:

```bash
claude plugin list 2>/dev/null | grep -i my-secretary
```

- 表示されたバージョンを `${CLAUDE_PLUGIN_ROOT}/.claude-plugin/plugin.json` の
  `version` と見比べる（同じなら本体は最新）。
- 本体が古い場合の更新方法を案内する:
  - **デスクトップアプリ**: チャットで「`my-secretary プラグインを最新に更新してください`」と頼む
    （AI が `claude plugin update my-secretary@my-secretary` を代行する）
  - **ターミナル**: `claude plugin update my-secretary@my-secretary`
  - どちらの場合も**更新後に Claude を再起動**（新しいスキル・フックは次のセッションから有効）
- 本体が古いままなら、ここで一度止めて「更新してから、もう一度 `/my-secretary:update` を実行してください」
  と伝える（古い本体のまま執務室だけ更新しても意味がないため）。

### 2. 執務室に不足しているものを補充する

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/init_workspace.py" . --plugin-root "${CLAUDE_PLUGIN_ROOT}"
```

- `python3` が無ければ `python` で再試行。どちらも無ければ
  `${CLAUDE_PLUGIN_ROOT}/workspace-skills/` の各 `SKILL.md` を
  `.claude/skills/<名前>/SKILL.md` へ自分で複製する（**既存は絶対に上書きしない**）。
- このスクリプトは**冪等**（既にあるものはスキップ）。出力の「作成／スキップ」一覧をそのまま見せる。
- ここで新しい執務室スキルが入る（例: 予定・人物・代筆など）。

> **ユーザーが自分で育てたスキルは上書きされない**。
> もし「新しい版のスキルに入れ替えたい」と言われたときだけ、該当ファイルを
> `.claude/skills/<名前>/SKILL.md.bak` に退避してから複製し直す（勝手にやらない）。

### 3. CLAUDE.md に不足している案内行を足す

`${CLAUDE_PLUGIN_ROOT}/skills/secretary-mode/references/claude-md-template.md` と
今の `CLAUDE.md` を見比べ、**足りない行だけ**を洗い出す（新しいフォルダ表の行・操作表の行・
先回り度など）。

1. 「こういう行を足します」と**差分を見せて承認を得る**
2. 承認されたら、該当セクションに**行を追記**する
   （1行目のマーカー・秘書プロフィールの値・心得の既存行は変更しない）
3. 先回り度の行が無い場合は「ふつう（標準）」として追記し、
   「`/my-secretary:character` で変えられます」と添える

### 4. 変更点をお披露目する

秘書の口調で、**今回から何ができるようになったか**を3つまで、
「言い方の例」つきで短く伝える（例: 「『明日14時に打ち合わせ』と言えば予定を覚えます」）。

最後に「気に入らなければ、その機能は使わなくて大丈夫です」の趣旨をひとこと添える。

## 困ったときの案内

- 更新したのにコマンドが増えない → **Claude を再起動**したか確認
- 新しいスキルが効かない → `/my-secretary:doctor` で不足を点検（不足があればこの update を再実行）
- 元に戻したい → プラグインを古いバージョンに戻す必要はほぼない。
  執務室のファイルは追加されただけなので、**使わなければ何も起きない**
