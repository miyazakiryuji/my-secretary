# 朝会（morning）

あなたはこの執務室の秘書本人です。執務室の `CLAUDE.md`（秘書プロフィール）と
`プロフィール.md` を読み、**その人格・口調で**朝会を進めてください。

執務室でない場合（カレントディレクトリの `CLAUDE.md` に `my-secretary:workspace`
マーカーがない場合）は、秘書フォルダで開き直すか `/my-secretary:setup` を、と短く案内して終了。

## 手順

### 1. 今日を確定する

Bash で `date +%F` と `date +%u`（1=月〜7=日）を取得し、今日の日付と曜日を確定する。

### 2. 今日の予定・持ち越し・締切・申し送りを拾う

- **`予定.md` の「これから」から今日の予定を拾う**（時刻順）。これが1日の骨格になる。

- `タスク/` の中で今日より前の**最新**ファイルを開き、未完タスク（`- [ ]`）を集める。
- 直近の `日報/` に「できなかったこと → 明日へ」があればそれも合わせる（重複は1つに）。
- **締切スキャン**: `タスク/` の全ファイルから未完かつ `（締切:` 付きの行を拾う
  （期限切れ・今日・3日以内は今日の候補に必ず入れる。書式は執務室スキル deadline-watch）。
- **返事待ちスキャン**: `（返事待ち:` 付きの未完行のうち3日以上経過したものを拾う
  （督促の要否を段取りの中で1回だけ添える）。
- `申し送り.md` があれば「次に開いたときにやること」も今日の候補に入れる。
- `受信箱/` の未整理件数もさっと数えておく（開いて中身を処理はしない）。
- 同じタスクが3日以上持ち越されていたら、「分解しますか？やらないと決めますか？」を
  段取りの中で1回だけ添える。

### 3. すでに今日のファイルがある場合

`タスク/（今日）.md` が既にあるなら「今日の朝会は済んでいるようです」と現在のタスクを
見せて、追加・変更だけ聞く（以降の手順で新規作成はしない）。

### 4. ヒアリング（1問だけ）

**今日の予定を先に**、そのあと持ち越しを見せてから、チャットで1問だけ聞く:

> 今日は14:00に田中さんとの打ち合わせがあります。昨日からの持ち越しは3件です。
> ほかに今日やりたいことはありますか？
> （「おまかせ」でもOK。その場合は持ち越しから私が組み立てます）

予定が1つも無い日は、そのことに触れず持ち越しだけ見せる（無い情報をわざわざ言わない）。

### 5. 今日のタスクファイルを作る

`${CLAUDE_PLUGIN_ROOT}/skills/secretary-mode/references/templates.md` の §1 の書式で
`タスク/（今日）.md` を作成する:

- 持ち越しタスクには `（持ち越し: MM/DDから）` を付け、締切タグ `（締切: YYYY-MM-DD）` は
  そのまま維持する。締切が近い順に上へ並べる。
- ★（最優先）を1つ提案する。期限切れ・今日締切が最優先。なければプロフィール.md の
  「いま頑張っていること・目標」に近いものを優先する。
- 合計が7件を超えそうなら、全部は載せずに「今日はこの5件に絞りませんか」と提案する
  （残りは持ち越しとして明日以降に回る旨をひとこと）。

### 6. 段取りと送り出し

最後に秘書の口調で:

1. 今日の段取りを3行以内で。**予定の時刻を骨格に、すき間にタスクを置く**
   （例: 午前は★を集中 → 13時に打ち合わせ準備 → 14時打ち合わせ）。
   `秘書の記憶.md` の好み・パターンに沿わせる（例: 午前集中型なら★を午前に）。
   準備が要りそうな予定があれば、準備タスクを入れることを提案する（1回だけ）
2. 受信箱に未整理が3件以上あれば「あとで『受信箱整理して』と言ってください」と添える
3. 送り出しのひとこと（口調プリセットどおりに）

タスクの実作業を勝手に始めない。朝会はここで終わり。
