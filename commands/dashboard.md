# ダッシュボード（dashboard）

あなたはこの執務室の秘書本人です。執務室の `CLAUDE.md`（秘書プロフィール）を読み、
**その人格・口調で**応対してください。このコマンドは**読み取りのみ**。何も変更しない。

執務室でない場合（カレントディレクトリの `CLAUDE.md` に `my-secretary:workspace`
マーカーがない場合）は、秘書フォルダで開き直すか `/my-secretary:setup` を、と短く案内して終了。

## 手順

1. Bash で `date +%F` と `date +%G-W%V` を取得する。
2. 各フォルダをスキャンして集計する:
   - **`予定.md`** … 今日の予定（時刻順）と、直近3日の予定の件数
   - `タスク/（今日）.md` … 完了数／全体数と★の内容（なければ「朝会まだ」）
   - **締切** … `タスク/` 全ファイルの未完かつ `（締切:` 付きの行を集計
     （期限切れ／今日／3日以内。書式は執務室スキル deadline-watch）
   - **返事待ち** … `（返事待ち:` 付きの未完行の件数と、3日以上経過の件数
   - `受信箱/` … 未整理の項目数（`[済→` で始まらない行）
   - `アイデア/` … 総数と直近7日の追加数
   - `ノート/` … 総数
   - `日報/` … 最新の日付
   - `週次レビュー/` … 最新の週
   - `申し送り.md` … あれば最終更新日時
   - `秘書の記憶.md` … 学び（箇条書き行）の件数。あわせて「一緒に働いて◯日目」
     （日付ファイル名の最古から）と記録の蓄積（全データフォルダの .md 総数）
   - 追加フォルダ（議事録など）があれば同様に総数
3. 次の形式で表示する（`スキル secretary-mode` の H 節と同じ形式）:

```
=== {{秘書名}} ダッシュボード（{{YYYY-MM-DD}}） ===

今日の予定   : 14:00 田中さんと打ち合わせ（ほか 直近3日で2件）
今日のタスク : 済 2 / 全 5（★ 提案資料のたたき台）
締切         : 🔴 期限切れ 1 ／ 🟠 今日 1 ／ 🟡 3日以内 2
返事待ち     : 3件（うち3日以上 1件）
受信箱       : 未整理 3件
アイデア     : 12件（今週 +2）
ノート       : 8件
日報         : 最終 07/23
週次レビュー : 最終 2026-W29
申し送り     : あり（07/23 22:10 更新）
秘書の記憶   : 24件（一緒に働いて 12日目・記録の蓄積 156件）
```

4. 最後に「おすすめの次の一手」を秘書の口調で1行だけ添える。判断の目安:
   - 今日のタスクファイルがない → 朝会（`/my-secretary:morning`）
   - 夕方以降で日報がまだ → 夕会（`/my-secretary:evening`）
   - 受信箱の未整理が5件以上 → 「受信箱整理して」
   - 週末・月曜で先週のレビューがない → `/my-secretary:weekly`
