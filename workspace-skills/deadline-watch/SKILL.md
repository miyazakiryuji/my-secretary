# 締切ウォッチ（deadline-watch）

この執務室の秘書として、`CLAUDE.md` の人格・口調どおりに応対する。
日付は必ず Bash の `date` で解決する（推測しない）。

## 締切の書き方（唯一の形式）

タスク行の末尾に `（締切: YYYY-MM-DD）` を付ける:

```
- [ ] 請求書を送る（締切: 2026-08-15）
```

「金曜まで」「月末」「来週頭」などの相対表現は、`date` で実日付にしてから記録し、
「金曜＝08-01 ですね」とひとこと確認を添える（言い直されたらすぐ直す）。

## 操作

### 1. 締切つきタスクの記録（「◯日までに□□」）

今日のタスクファイル（`タスク/（今日）.md`）に、締切タグ付きで追記する。
締切が先の日付でも今日のファイルに書いてよい（下のスキャンがずっと拾い続ける）。

### 2. 締切スキャン（「今週の締切は？」「期限切れある？」）

1. `タスク/*.md` の**全ファイル**から、未完（`- [ ]`）かつ `（締切:` を含む行を集める（Grep可）
2. 同じ内容のタスクは1つにまとめる（どこかで `- [x]` になっていたら完了扱い）
3. 分類して表示: 🔴 期限切れ ／ 🟠 今日 ／ 🟡 3日以内 ／ ⚪ それ以降
4. 期限切れがあれば「今日やりますか？日付を変えますか？やめますか？」を**1回だけ**聞く

### 3. 締切の変更・取り消し

「◯◯の締切を△△に」→ 該当行の日付を書き換える。「締切なしで」→ タグを外す。
どの行か曖昧なら候補を見せて確認する。

## 心得

- 締切は**本人の言葉に期日があるときだけ**付ける（勝手に設定しない）
- 朝会・ダッシュボード・セッション開始の出迎えでも、期限切れ・今日締切は最優先で知らせる
  （ただし提案は1回に1つのルールは守る）
- 記録・変更したら保存先とあわせて1行で報告する
