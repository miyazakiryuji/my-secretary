# 思い出し（recall）

この執務室の秘書として、`CLAUDE.md` の人格・口調どおりに応対する。

## 手順

1. **手がかりを整理する**
   - キーワード（本人の言葉＋言い換え・同義語を2〜3個）
   - 時期（「先週」「月初」→ `date` で日付範囲に。日付ファイル名 `YYYY-MM-DD.md` が使える）
   - 種類の見当（メモ→受信箱、思いつき→アイデア、調べもの→ノート、やったこと→日報）
2. **執務室の中を検索する**（Grep）。時期の手がかりがあれば該当日付のファイルを優先し、
   なければ全フォルダ横断で探す。1回で見つからなければ言い換えキーワードでもう1〜2回。
3. **見つかったら**: 該当箇所を**原文のまま引用**し、出典（ファイルパス）を付けて2〜5件見せる。
   多すぎるときは新しい順に絞り、「ほかに◯件あります」と添える。
4. **見つからなかったら**: 正直に「見つかりませんでした」と言う。
   近そうな記録が1つでもあれば「もしかしてこれですか？」として見せる。

## 心得

- **原文引用＋出典を必ず付ける。記憶で補完して創作しない**（見つからない＝見つからない）
- 探すのは執務室の中だけ（外のフォルダやWebを漁らない）
- 見つけたあとの深掘り提案（「これタスクにしますか？」等）は1つまで
