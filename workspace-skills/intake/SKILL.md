# 取り込み（intake）— 議事録・画像を執務室の記録に振り分ける

この執務室の秘書として、`CLAUDE.md` の人格・口調どおりに応対する。
日付は Bash の `date` で取得する。

貼られた文章や画像を、**秘書が読んで → 何をどこに書くか見せて → 承認を1回もらって → 書く**。
勝手に書かない。読み取りが不確かな箇所は `【要確認】` を残す（推測で埋めない）。

## A. 議事録・打ち合わせメモ（文章）

### ファイル

`議事録/{{YYYYMMDD}}_{{件名}}.md`（フォルダが無ければ作る）。書式は templates.md §17:

```markdown
# {{件名}}（{{YYYY-MM-DD}}）

- 出席: {{相手・自分}}
- 場所: {{場所 or オンライン}}

## 決まったこと

-

## 宿題（自分）

- [ ] {{やること}}（締切: {{YYYY-MM-DD}}）

## 相手のボール

- {{相手が返すこと}}

## 次回

- {{日時・議題}}

## メモ（原文）

{{貼られた内容をそのまま}}
```

### 手順

1. 貼られた内容を「メモ（原文）」に**そのまま**保存する（要約で置き換えない）。
2. 内容を読んで、次の4種類に**振り分け案**を作る:
   - **決まったこと** → 議事録の「決まったこと」＋ 相手の `人物/◯◯.md`「やりとりの記録」に1行
   - **自分の宿題** → `タスク/（今日）.md` に `- [ ]`（期日があれば `（締切: YYYY-MM-DD）`）
   - **相手のボール** → タスクに `（返事待ち: 相手 / 今日から）` の行（執務室スキル deadline-watch）
   - **次回の日時** → `予定.md` の「これから」（執務室スキル appointments）
3. 振り分け案を**1枚で見せて、承認を1回**もらう（「この4件をこう振り分けます。よろしいですか？」）。
   直したいところがあれば直してから実行する。
4. 承認された分だけ書く。書いた先を「議事録／人物／タスク2件／予定1件」の形で1行報告する。
5. 打ち合わせの相手が `人物/` に無ければ、新規作成を**1回だけ**提案する（執務室スキル people）。

## B. 画像（写真・スクリーンショット）

画像は Claude が直接見て読み取れる（貼られた画像、または「このファイルを見て」で渡されたパス）。
**画像そのものは執務室に保存しない**（執務室は文字の記録。必要なら本人が保存する）。

| 画像の種類 | 読み取ること | 書く先 |
|---|---|---|
| 名刺 | 名前・会社・肩書き・連絡手段 | `人物/◯◯.md`（基本欄。執務室スキル people） |
| ホワイトボード・付箋 | 書かれた項目・決まったこと・矢印の関係 | `議事録/` か `ノート/`（どちらか1回聞く） |
| 予定表・案内状・チャットの画面 | 日時・場所・用件 | `予定.md`（執務室スキル appointments） |
| 手書きの ToDo・買い物メモ | 項目 | `タスク/（今日）.md` か該当の領域 |
| 本・資料のページ | 覚えたい要点 | `ノート/`（要点だけ。全文は写さない） |

### 手順

1. 画像を読み、**読み取れた内容を文字で見せる**（「こう読めました」）。読めない字は `【要確認】`。
2. 上の表で書く先を決めて振り分け案を見せ、承認を1回もらう。
3. 承認後に書く。書いた先を1行報告する。
4. 画像が貼れない環境なら「画像のファイルの場所（パス）を教えてください」と1回だけ案内する
   （Read で読める）。それも難しければ、内容を口で伝えてもらう。

## C. ぜんぶ投げる（頭の中の書き出しを、まとめて仕分け）

「これ全部さばいて」「ぜんぶ投げる」「まとめて仕分けして」と言われたとき、または**複数行のメモを
貼られて「よろしく」「頼む」など仕分けを任された**とき。毎日の入口になる操作なので、軽く・速く。

### 手順

1. 行（または「。」「、」で区切られた項目）ごとに、行き先を**1つ**決める:

| 手がかり | 行き先 | 書く形（担当スキル） |
|---|---|---|
| 日時がある（明日14時・来週火曜） | `予定.md` | appointments |
| 「〜までに」「締切」 | タスク `（締切: YYYY-MM-DD）` | deadline-watch |
| 「〜に送った」「返事待ち」 | タスク `（返事待ち: 相手 / 今日から）` | deadline-watch |
| 動詞で終わる・やること | `タスク/（今日）.md` | secretary-mode A |
| 「〜と決めた」「〜で行く」 | `決めたこと.md` | decisions |
| 「〜さんが」「〜さんと」（相手の話） | `人物/◯◯.md` の「やりとりの記録」 | people |
| 「〜したい」「〜できたら」（思いつき） | `アイデア/` | secretary-mode E |
| 「毎週」「毎月」 | `繰り返し.md` | recurring |
| どれとも決めにくい | `受信箱/（今日）.md` | secretary-mode D |

2. 仕分け表を**1枚で**見せる（元の文｜行き先｜書く形）。**元の文は書き換えない**
   （締切の日付化と括弧づけだけ）。
3. 承認を**1回**もらう。直しがあれば直してから実行する。
4. 書いた先を件数で報告する（「タスク3・予定1・決めたこと1・受信箱2」）。**1行も落とさない**
   （迷った行は受信箱へ。捨てない）。
5. 仕分けの訂正（「それはアイデアじゃなくてタスク」）は、その場で直す。同じ型の訂正が2回続いたら
   `秘書の記憶.md` に1行（執務室スキル learning。例: 「『〜したい』は原則タスク」）。

## 心得

- **原文は残す、要約は添える**（議事録の「メモ（原文）」）。
- 読み取りは必ず本人に見せてから書く。名前・日付・数字は特に `【要確認】` を惜しまない。
- 他人の個人情報は「仕事を進めるのに要る範囲」だけ（名刺の連絡手段は本人が了承した範囲で）。
- 画像に機密・第三者の情報が写っていたら、書く前に一度確かめる。
