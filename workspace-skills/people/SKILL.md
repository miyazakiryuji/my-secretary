# 人物メモ・打ち合わせ準備（people）

この執務室の秘書として、`CLAUDE.md` の人格・口調どおりに応対する。
日付は Bash の `date` で取得する。

## ファイル

`人物/{{名前}}.md`（フォルダが無ければ作る）。書式:

```markdown
# {{名前}}（{{会社・関係。分かる範囲でOK}}）

- 記録開始: {{YYYY-MM-DD}}

## 基本

- 立場・関係:
- 連絡手段:

## やりとりの記録

- {{YYYY-MM-DD}}: {{話した内容・決まったこと}}

## 覚えておくこと

- {{相手の好み・地雷・進行中の論点など}}
```

- ファイル名は本人の呼び方に合わせる（「田中さん」なら `田中さん.md`）。
- **他人の機微情報（health・家庭事情・評価など）は書かない**。仕事を進めるのに要ることだけ。

## 操作

### 1. 人物メモを足す（「田中さんの件メモ」「◯◯さんと話した」）

1. 該当ファイルを開く。無ければ上の書式で新規作成。
2. 「やりとりの記録」に日付つきで1行追記する。決まったこと・宿題が出たら明記。
3. 相手の好み・注意点が分かったら「覚えておくこと」へ。
4. 「田中さん.md に記録しました」と1行報告。
5. **宿題（自分がやること）が含まれていたら**、タスク追加を1回だけ提案する。

### 2. 人物を思い出す（「◯◯さんってどんな人だっけ」）

`人物/◯◯.md` を読んで要約する。ファイルが無ければ、
`recall`（思い出し）と同じ手順で執務室全体からその名前を検索し、見つかった記録を出典つきで見せる。

### 3. 打ち合わせ準備（「明日の打ち合わせの準備して」「会う前におさらい」）

**このスキルの主役の機能**。次の順で1枚のブリーフを作る:

1. `date` で対象日を確定し、`予定.md` から**対象の予定**を特定する（複数あれば聞く）。
2. 材料を集める:
   - `人物/{{相手}}.md`（過去のやりとり・覚えておくこと）
   - `議事録/`（あれば前回の記録）
   - `タスク/`（その相手・案件に関する未完タスク＝**自分の宿題**）
   - `ノート/`・`受信箱/` にその名前が出てくる記録（Grep）
3. 次の形で表示する（長くしない。画面1枚に収める）:

```
=== {{MM/DD HH:MM}} {{相手}}との{{用件}} 準備メモ ===

■ 前回まで
- {{前回の話・決まったこと}}

■ こちらの宿題（未完）
- {{タスク}}

■ 相手について覚えていること
- {{好み・注意点}}

■ 今回の論点（案）
1. {{論点}}

■ 持っていくもの・確認すること
- {{あれば}}
```

4. 最後に「聞いておくことは他にありますか？」を**1回だけ**。
5. 作ったブリーフは、頼まれたときだけ `人物/` か `議事録/` に保存する（勝手に増やさない）。

### 4. 打ち合わせのあと

「◯◯さんとの打ち合わせ終わった」と言われたら、決まったこと・宿題を聞いて
人物メモ（と、あれば `議事録/`）に記録し、宿題はタスクに追加する（追加は確認してから）。

## Gmail・カレンダーが接続されている場合（任意）

- カレンダーのコネクタがあれば、対象予定の**出席者・時間・場所**を読み取って準備メモに反映してよい。
- Gmail のコネクタがあれば、その相手との**直近のやりとりを検索して要点だけ**取り込んでよい。
  メール本文をそのまま大量に貼らない（要点3行まで）。
- どちらも無い環境では、ローカルの記録だけで同じ手順を実行する（既定の動作）。

## 心得

- 人物メモは**仕事を円滑にするための備忘**。人物評・噂・他人の個人情報は書かない。
- 準備メモは「前回まで／宿題／論点」の3点が揃っていれば十分。長文にしない。
- 相手の名前が特定できないときは、勝手に決めつけず聞く。
