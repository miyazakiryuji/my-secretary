# 時間の見積もりと実績（estimates）— 見積もりの癖を秘書が覚える

この執務室の秘書として、`CLAUDE.md` の人格・口調どおりに応対する。

段取りが崩れるいちばんの原因は「見積もりの甘さ」。タスクに**見積もり**を添え、夕会で**実績**を聞き、
週次で**ずれの傾向**を見る。傾向は `秘書の記憶.md` に残り、次の朝会の段取りに効く。
**見積もりは任意**（付けなくても何も起きない）。

## 書式（templates.md §1 のタスク行に添える）

```
- [ ] 提案資料のたたき台（見積: 30分）
- [x] 提案資料のたたき台（見積: 30分 ／ 実績: 50分）
```

- 単位は「分」か「時間」（`（見積: 2時間）` も可。集計では分に直す）。
- 見積・実績とも**同じ括弧の中**に書く（締切・持ち越しの括弧とは別に付けてよい）。

## 操作

### 1. 見積もりつきで追加する（「30分くらいで◯◯」「◯◯は2時間かかりそう」）

- 通常のタスク追加（secretary-mode A）に `（見積: ◯分）` を添えるだけ。
- 見積もりが言われなかったタスクには**付けない**（聞かない）。
- 今日の見積もりの合計が**6時間を超えたら**、段取りの中で1回だけ「今日は詰め込みすぎかもしれません」と添える。

### 2. 実績を残す（「◯◯終わった、実際は1時間」「実績50分」）

- 該当タスクを `- [x]` にし、括弧に ` ／ 実績: ◯分` を足す。
- 実績が言われなかった完了は、**夕会でまとめて聞く**（下）。日中には聞かない。

### 3. 夕会で聞く（evening コマンド側）

- 今日のタスクに `（見積:` があり実績が無いものがあれば、ふりかえりの1問に**まとめて**添える:
  「見積もりつきの2件、実際はどのくらいかかりましたか？（だいたいでOK・分からなければ空欄で）」
- 答えた分だけ `／ 実績: ◯分` を追記する。答えなかったものは空欄のまま（催促しない）。

### 4. 傾向を見る（「見積もりの癖は？」「今週どれくらいずれた？」／週次レビュー側）

1. `タスク/` の対象期間（指定がなければ今週）から、見積・実績が両方あるタスクを集める。
2. 次を出す: 件数／見積合計と実績合計／倍率（実績÷見積）／いちばんずれたタスク。
3. 見やすく1枚で:

```
=== 見積もりと実績（{{M/D}}〜{{M/D}}） ===
対象: 6件 ／ 見積 3時間20分 → 実績 5時間10分（1.55倍）
いちばんずれた: 「提案資料のたたき台」 30分 → 1時間30分
傾向: 資料づくりは見積もりの1.5〜2倍かかる
```

4. **3件以上**あって傾向が言えるときだけ、`秘書の記憶.md`「仕事のパターン」に1行を提案する
   （例: 「資料づくりは見積もりの1.5倍で見る」）。承認されたら書く（執務室スキル learning）。
   件数が少ないときは提案しない（決めつけない）。

## 朝会での使われ方（morning コマンド側）

- `秘書の記憶.md` に見積もりの傾向があれば、段取りで**それを踏まえて**時間配分を示す
  （「資料づくりは1.5倍で見て、午前いっぱいにしましょう」）。
- 本人の見積もりを勝手に書き換えない。傾向は**添える**だけ。

## 心得

- 見積もりは責める材料ではない。ずれは「癖」として扱い、段取りに活かす。
- 実績を聞くのは1日1回（夕会）だけ。日中に「何分かかりました？」と聞かない。
- 3件未満で傾向を語らない。
