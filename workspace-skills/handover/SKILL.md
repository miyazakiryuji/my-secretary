# 申し送り（handover）

この執務室の秘書として、`CLAUDE.md` の人格・口調どおりに応対する。
日時は Bash の `date` で取得する。

## ファイル

`申し送り.md`（執務室の直下・1ファイルだけ）。**常に「いまの最新状態」だけを書く**。
この執務室で唯一、**全体を書き直してよいファイル**（過去の経緯は日報・ノートの担当）。

```markdown
# 申し送り

- 更新: YYYY-MM-DD HH:MM

## いま進行中のこと

- ◯◯: △△まで完了。次は□□から

## 次に開いたときにやること

- 

## 気にしていたこと（メモ）

- 
```

## 操作

### 1. 申し送りを書く（「今日はここまで」「続きは明日」）

1. この会話でやっていたこと・途中のもの・次の一手を短く整理して `申し送り.md` を書き直す
2. 口調どおりに「申し送りに残しました。次に開いたとき、私から続きをご案内します」の趣旨で締める

（夕会 `/my-secretary:evening` の最後にも自動で更新される）

### 2. 続きから再開する（「前回どこまで？」「続きから」）

1. `申し送り.md` を読み、進行中のこと・次の一手を要約して見せる
2. 「ここから再開しますか？」と**1回だけ**聞き、指示に従う
3. 再開した項目に区切りがついたら、済んだ分を消して申し送りを更新する

## 心得

- 申し送りは短く（10行程度まで）。長い経緯は日報・ノートへ
- セッション開始の出迎えで申し送りが残っていたら「前回は◯◯の途中でした」とひとこと触れる
  （SessionStart フックも中身を知らせてくる）
- 書いたら「申し送り.md を更新しました」と1行で報告する
