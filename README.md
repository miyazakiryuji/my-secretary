# my-secretary — 自分専用のAI秘書をつくる Claude Code プラグイン

面談で秘書の**名前と呼び名**を決めるだけで、あなた専用の秘書が誕生します。
性別・性格・口調は `/my-secretary:character` で、**決めたくなったときにいつでも**設定・変更できます。

そしてこの秘書は、**使えば使うほど育ちます**。メモ・日報・会話からあなたの好み・言い方・
仕事のパターンを `秘書の記憶.md` に蓄え、出迎え・段取り・応対がだんだん「あなた仕様」に
なっていきます。訂正すれば覚え直し、記録が溜まるほど「あれどこだっけ？」に強くなる——
**毎日の吐き出しがそのまま秘書の成長になる**のがこのプラグインのテーマです。
朝会・夕会・週次レビューの「リズム」と、話しかけるだけのタスク・メモ管理を、
**すべてローカルの Markdown ファイルだけ**で回します（外部サービス連携なし）。

## 動作環境 — Claude Code デスクトップアプリ前提

本プラグインは **Claude Code デスクトップアプリ（Mac / Windows）** での利用を前提に
設計しています。**ターミナル操作は不要**——「フォルダを開く」→「チャット欄に話しかける」
だけで、インストールから毎日の利用まですべて完結します。

- 推奨環境: Claude Code デスクトップアプリ（最新版・有料プラン）
- インストールも設定も、アプリのチャット欄へのコピペだけ（GitHub アカウント不要）
- CLI（ターミナル版 Claude Code）でもそのまま動きますが、本 README の手順は
  デスクトップアプリの画面を想定して書いています

## インストール

**デスクトップアプリの場合（おすすめ・コピペ1行）** — Code タブのチャット欄に、この一文を送るだけ:

```
miyazakiryuji/my-secretary というプラグインを追加して、インストールしてください
```

AI がマーケットプレイス登録からインストールまで代行してくれます
（デスクトップアプリでは `/plugin` コマンドが直接使えないため、この方式が確実です）。

**ターミナル（CLI）の場合** — 次の2行:

```
claude plugin marketplace add miyazakiryuji/my-secretary
claude plugin install my-secretary@my-secretary
```

（CLI の対話セッション内なら `/plugin marketplace add miyazakiryuji/my-secretary` →
`/plugin install my-secretary@my-secretary` でも同じです）

インストール後は Claude Code / デスクトップアプリを**一度再起動**してください
（「開くだけで出迎え」のフックが再起動後に有効になります）。

## 使いはじめ（3ステップ）

1. 秘書専用の新しいフォルダ（例: `マイ秘書`）を作り、デスクトップアプリの
   「フォルダを開く」でそのフォルダを開く
2. `/my-secretary:setup` … 面談に答えると、秘書と執務室（フォルダ一式）ができる
3. 次回からは**そのフォルダで開くだけ**で、あなたの秘書が名前つき・その口調で出迎えます

プラグインの SessionStart フックが執務室を自動検出するので、**最初のひとことは
「おはよう」でも用件でも、何なら「あ」でもOK** — 何を打っても秘書として出迎えます
（コマンドを覚えていなくても大丈夫）。執務室以外のフォルダでは、このフックは何もしません。

さらに、**開いている間は秘書のほうから声をかけます**。14時の打ち合わせが近づけば
「まもなくお時間です」、夕方になって日報がまだなら「そろそろ夕会にしましょう」——
時間の経過に気づいて、そっと1行添えるだけ。**同じ話題は1回だけ**で、
うるさければ `/my-secretary:character` の**先回り度**を「控えめ」にできます。

## できること

### 1日のリズム（コマンド）

| コマンド | いつ | すること |
|---|---|---|
| `/my-secretary:morning` | 朝 | 昨日の持ち越しを拾って、今日の段取りを一緒に決める |
| `/my-secretary:evening` | 夜 | 今日をふりかえって、日報を自動でまとめる |
| `/my-secretary:weekly` | 週末 | 1週間分を集計して週次レビューを作る |
| `/my-secretary:monthly` | 月末・月初 | 1か月分をまとめ、プロフィールの目標と照らして来月の重点を決める |
| `/my-secretary:role` | いつでも | 仕事の型（営業・事務・管理職・フリーランス・講師・学生・家庭）に合わせて気くばりを決める・変える |
| `/my-secretary:dashboard` | いつでも | 全体のようすをひと目で表示（読み取りのみ） |
| `/my-secretary:character` | いつでも | 秘書のキャラ（性別・性格・口調・**先回り度**・名前）を決める・変える |
| `/my-secretary:update` | 更新が来たら | 新機能を今の執務室に取り込む（記録・人格はそのまま） |
| `/my-secretary:doctor` | 困ったら | 環境チェック（読み取りのみ） |

朝会・夕会はコマンドを打たなくても、**「おはよう」「おつかれさま」と話しかけるだけ**で
始まります（秘書が時間帯と記録の状態を見て判断します）。

### ふだんは話しかけるだけ（コマンド不要）

| 言い方の例 | 秘書がすること |
|---|---|
| 「おはよう」 | 挨拶と一緒に朝会が始まる |
| 「おつかれさま」 | 夕方以降なら夕会が始まって、日報ができる |
| 「タスク追加 ◯◯」 | 今日のタスクに追加 |
| 「◯◯終わったよ」 | タスクを完了にして労ってくれる |
| 「今日のタスクは？」 | 今日のタスクを表示 |
| 「メモ ◯◯」 | 受信箱に書き留める |
| 「アイデア ◯◯」 | アイデアを1ファイルにして保存 |
| 「明日14時に打ち合わせ」 | 予定（アポ）として記録。当日いちばんに知らせてくれる |
| 「今日の予定は？」「今週の予定」 | 予定を時系列で表示 |
| 「田中さんの件メモ」「どんな人だっけ」 | 人物ごとにメモを貯めて、要約してくれる |
| 「明日の打ち合わせの準備して」 | 前回の話・自分の宿題・論点を1枚のメモに |
| 「お礼メール書いて」「断りの文案」 | 下書きを作る（**送信はしない**） |
| 「◯◯さんに送った、返事待ち」 | 相手のボールとして管理。3日過ぎたら教えてくれる |
| 「8/15までに◯◯」 | 締切つきで記録。朝会や出迎えのとき最優先で教えてくれる |
| 「今週の締切は？」 | 期限切れ・今日・近日の締切を一覧 |
| 「あれどこだっけ？」 | 書き溜めた記録を検索して、原文＋出典つきで思い出す |
| 「今日はここまで」 | 申し送りを書いて、次回は「前回の続きから」案内してくれる |
| 「覚えておいて」「今後は◯◯して」 | 秘書の記憶に残して、その場から応対に反映（「忘れて」で削除） |
| 「私のこと何覚えてる？」 | 育った記憶を一覧で見せてくれる |
| 「毎週月曜10時に定例」「毎月1日に請求書」 | 繰り返しとして登録。朝会で当日分を自動で載せ、定例の直前には声をかける |
| 「請求書の手順を覚えて」→ 次回「請求書やろう」 | 定型業務の手順をレシピにして、次回は1手順ずつ一緒に進める。**やるほど手順が磨かれる** |
| 「30分くらいで◯◯」 | 見積もりつきで記録。夕会で実績を聞き、週次で見積もりの癖を覚える |
| 「この議事録取り込んで」「この名刺を人物メモに」 | 読み取った内容を見せてから、人物・予定・タスク・返事待ちへ振り分け |
| 「朝会で体調も聞いて」「読書リストのフォルダ足して」 | 朝会・夕会で聞くことや、管理する領域を自分仕様に |
| 「受信箱整理して」 | メモを各フォルダへ仕分け（承認してから移動） |

どれも言い方は自由です。「おはよー」「今日終わり！」「これメモっといて」など、
**意味が伝われば秘書がくみ取ります**（完全一致のコマンドではありません）。

### 秘書のキャラ（`/my-secretary:character` でいつでも設定・変更）

セットアップ直後は標準キャラ（あたたかい秘書 × しっかり者）で始まります。
決めたくなったタイミングで、性別・性格・口調を選べます:

| 口調プリセット | 例 |
|---|---|
| きっちり秘書 | 「かしこまりました。タスクに追加しました。本日は残り3件です。」 |
| あたたかい秘書 | 「追加しておきました！今日もいいペースですよ☺️」 |
| フランクな相棒 | 「おっけー、入れといた！残り3つね」 |
| 執事 | 「かしこまりました、◯◯様。本日の予定に加えております。」 |

性格（しっかり者・世話焼き ／ 明るい元気印 ／ クール・冷静沈着 ／ 天然・マイペース）は
口調とは別に選べて、組み合わせは自由（例: 執事×天然）。どれも自由記述（関西弁など）OK。

### 仕事の型（`/my-secretary:role`。面談のお仕事から秘書が提案）

秘書は「誰に仕えるか」で気くばりが変わります。営業なら「今日の商談と追いかける案件」、
フリーランスなら「今日の納期と請求の締切」、講師なら「今日の講義と準備の残り」——
型を決めると、**追加フォルダ／朝会・夕会で必ず聞くこと／気をつけること／定型業務の候補／
記憶の初期値**の5つが変わります（名前・口調・記録は変わりません）。

| 型 | 追加フォルダ | 朝会で必ず聞くこと |
|---|---|---|
| 営業・顧客対応 | 商談/ | 今日の商談・訪問と、追いかける案件 |
| 企画・事務・バックオフィス | 依頼/ | 今日の締切と、受けている依頼の状況 |
| 管理職・チームリーダー | メンバー/・会議/ | 今日の会議と、メンバーに返す判断 |
| フリーランス・個人事業主 | 案件/・請求・契約/ | 今日の納期と、見積・請求の締切 |
| 講師・教育 | 講義準備/・質問対応/ | 今日の講義と、準備の残り |
| 学生・研究 | 授業/・課題/ | 今日の授業と、提出期限が近い課題 |
| 家庭・プライベート中心 | 家のこと/・買い物/ | 今日の家の予定と買うもの |

自由記述もOK。面談では質問を増やさず、お仕事の答えから秘書が近い型を提案します。

### 定型業務のレシピ（「使うほど育つ」の本題）

くり返す仕事は「◯◯の手順を覚えて」でレシピにできます。次回は「◯◯やろう」のひとことで、
秘書が**1手順ずつ**一緒に進め、終わったら「手順で直すところは？」と1回だけ聞いて
レシピに戻します。やるたびに手順が磨かれ、つまずきが「注意点」に溜まっていきます。
金額・口座・パスワードはレシピに書きません（「どこを見れば分かるか」だけ）。

## できあがる執務室（フォルダ構成）

```
マイ秘書/
├── CLAUDE.md              ← 秘書の人格・ルール（開くだけで読み込まれる）
├── プロフィール.md         ← あなたの基本情報と目標
├── 秘書の記憶.md           ← 秘書が学んだあなたの好み・パターン（使うほど育つ）
├── 申し送り.md             ← 前回の続き（秘書が管理。次回「続きから」の種）
├── はじめにお読みください.md
├── 予定.md                ← 日時のある約束（アポ）。当日いちばんに知らせてくれる
├── 繰り返し.md             ← 毎週・毎月くり返す予定とタスク（朝会が当日分を展開）
├── 朝会・夕会の項目.md      ← 朝会・夕会で必ず聞くこと（「朝会で体調も聞いて」で増える）
├── 人物/・下書き/・議事録/  ← 人物メモ・代筆した文章・打ち合わせの取り込み（必要になったとき作られる）
├── 業務手順/               ← 定型業務のレシピ（「◯◯の手順を覚えて」で作られ、やるほど磨かれる）
├── .claude/skills/        ← この執務室専用の秘書スキル12点（予定・締切・思い出し・申し送り・学習・人物・代筆・定型業務・自分仕様・繰り返し・見積もり・取り込み）
├── 受信箱/                ← 何でも書き捨てるメモ（1日1ファイル）
├── タスク/                ← 1日1ファイルのタスクリスト
├── アイデア/              ← 1アイデア1ファイル
├── ノート/                ← 調べたこと・ナレッジ
├── 日報/                  ← 夕会で秘書が書く日報
├── 週次レビュー/          ← 週ごとのふりかえり
└── 月次レビュー/          ← 月ごとのふりかえりと目標の照合
```

`.claude/skills/` の12スキル（appointments＝予定／deadline-watch＝締切・返事待ち／
recall＝思い出し／handover＝申し送り／learning＝学習・記憶／people＝人物・打ち合わせ準備／
drafting＝代筆／routines＝定型業務レシピ／customize＝自分仕様／recurring＝繰り返し／
estimates＝見積もりと実績／intake＝議事録・画像の取り込み）は、
**その執務室フォルダで開いたときだけ**有効になる秘書専用スキルです。
中身はただの Markdown なので、開いて自分好みに育てることもできます。

## 更新のしかた（すでに使っている人）

プラグインが新しくなったら、**2ステップ**で今の秘書に取り込めます。
記録も秘書の人格・キャラ設定も、そのまま残ります。

1. **本体を更新** — デスクトップアプリならチャットで
   「`my-secretary プラグインを最新に更新してください`」と頼む
   （ターミナルなら `claude plugin update my-secretary@my-secretary`）→ **Claude を再起動**
2. **秘書フォルダを開いて `/my-secretary:update`** — 新しいスキルや案内行だけが追加されます
   （既存ファイルは上書きしません。自分で育てたスキルもそのまま）

うまく入ったか不安なときは `/my-secretary:doctor` で点検できます。

## Gmail / Google カレンダー連携（任意）

Claude の Google Workspace コネクタを接続すると、朝会でカレンダーの予定を読んだり、
打ち合わせ準備に直近のメール要点を含めたり、返信の下書きを Gmail に保存したりできます
（**送信はしません**）。接続しなくても全機能が動きます。

→ 手順・できること/できないこと・使い方レシピは
[`docs/連携ガイド_GmailとGoogleカレンダー.md`](docs/連携ガイド_GmailとGoogleカレンダー.md)

ぜんぶただの Markdown（テキスト）ファイルです。手で開いて眺めても、直してもOK。
**毎日吐き出した記録がそのまま自分の資産として積み上がる**のがこの秘書の狙いです。

```
│       └── references/

├── workspace-skills/             # 執務室に複製される専用スキル12点

├── hooks/
│   └── hooks.json                # SessionStart（開くだけで出迎え）＋ UserPromptSubmit（自発的な声かけ）

│   ├── doctor.py                 # 環境チェック（読み取りのみ）
│   ├── recurring.py              # 繰り返し.md を読む部品（出迎え・声かけ・doctor が共用）

└── README.md
```

## 注意

- 会社の機密情報や、他人の個人情報は、秘書フォルダに書かないでください。
- この秘書はローカル完結です。外部サービスへの送信・連携は行いません。
